# 图册示例

用仓库现有的早餐、雨巷、海岸三张已完成的 Plog 成图，以“慢慢吃吧 → 街慢下来 → 今天很慢”串联故事，不表示照片来自同一天或同一次旅行。原素材说明及权利状态沿用 [素材清单](../readme/MANIFEST.md)。本例不调用图片生成服务。

在仓库根目录运行，输出放在仓库外的全新位置：

```sh
.venv/bin/python plog/scripts/album.py examples/album/story.json --output /tmp/plog-album-demo.html
```

用浏览器打开生成文件，即可打开书本、翻页、自动翻阅，或选择横屏/竖屏并导出完整翻书动画。格式选项按浏览器支持显示 MP4/WebM；录制时保持页面前台。另有大图阅读、保存书本和打印入口。修改 `story.json` 的书名、页面顺序与配文，再选择新的输出文件名导出。

此示例的浅砂色纸封来自早餐的暖木色，蓝灰文字呼应雨巷与海岸；具体设计和理由保存在 `story.json` 的 `design` 中，只属于这组照片。更换照片或故事时重新设计，不能将其当成统一主题。
