# Plog 故事书

用户要把多张照片串成一本可打开、可翻页、可导出翻书动画的书时使用。成品是一本有封面、左右书页、书脊与翻页动作的 HTML 故事书。每张内容页收录一张完整 Plog 成图；先编排全书故事，再逐页创作，最后装订。`album.py` 负责把明确的图册稿与图片装订成书，不读图、不调用图片生成，也不能把原照片自动变成 Plog。

## 编排全书，再创作每页

沿用 [对话表达](conversation.md)，承接用户的主题、顺序、背景和已有授权。用户指定顺序优先；未指定时按故事与视觉节奏安排。对原照片使用 [输入与准备](runtime.md#输入与准备)，服务和场景边界按 [场景与隐私](people-and-privacy.md)。已有 Plog 作品按 [版本操作](revisions.md) 的 delivery 取得所选且通过文件检查的版本。

先逐张观察，找出由画面或用户说明支持的共同线索，为全书写下开场、展开和收束。给每页明确的叙事任务与确切配文：这一页承接什么、留下什么、下一页怎样继续。可以让一个词、动作或感受在后页变化，而不是给每张重复同一句标题。照片关联弱时，用“几段日常”这样的松散主题；不编造连续事件。日期、地点、人物身份与关系只使用用户确认的信息，视觉相似不证明是同一个人或同一天。

新照片默认按全书稿逐张进入 [主流程](../SKILL.md#4-确定方案与编辑底图)，将文案、光色、字体与照片构图一起创作成完整 Plog。全书协调语气和阅读节奏，每页仍按画面决定设计。每张生成与核验独立进行，保留自己的原图及版本。失败页明确报告，不用原图静默顶替；完整故事书须全部所需页通过核验。有现成 Plog 时可以直接装订，不重复生成图片；需要改变画内文字时先完成该页定向修改。

书页以完整 Plog 为主体，保持比例，完整显示画内文字；页脚只放简短过渡旁白。不要用照片旁边的一大段文字代替 Plog 设计。用户明确要求原照书时可以收录原图，但须与默认 Plog 故事书区分。确认原话逐字保留；创作对白标明为创作，不当作真实经历。

## 每本书独立决定装帧

书的外观由这一册的照片、故事和用户偏好决定。先看照片的光色、主体、构图与已有 Plog 字形，再理解叙事的情绪和节奏，形成这一册的封面、材质、用色、字体、留白与翻页速度。用户明确的偏好优先；更换照片、主题或故事后重新判断。纯文字修订或调整少量顺序时保留已选装帧，除非修改影响全书方向。

把具体画面证据与选择理由写进图册稿的 `design.rationale`。配色可来自照片，也可为叙事选择对比色；不能把“提取主色”当成故事理解，更不能按旅行、儿童等关键词机械分配主题。样册的绿色、布面、烫金或某个字体都只属于那次创作，不是默认风格。

`design` 记录本册实际采用的设计，并由同一渲染器用于阅读和视频。没有设计记录时，Agent 先完成这一步再导出；不要填一份固定默认值绕过。下面的颜色仅示意早餐暖木色与雨巷蓝色如何进入此册，不能照搬到其他照片。

## 图册稿与装订

在用户指定的私密作品目录保存 `album-v001.json`。默认目录沿用 [输出位置](runtime.md#输出和中断)。图册稿记录书名、故事文字、所选成图路径、顺序和本册装帧决定；不放进分享页面，不保存授权、完整对话或原图元数据。

```json
  "title": "把日子\n放慢一点",
  "subtitle": "一餐、一条街、一片海",

    "palette": {
      "cover": "#e5d8bf",
      "cover_text": "#2e5161",
      "paper": "#faf7ee",
      "ink": "#304a51",
      "accent": "#a26c38",
      "stage": "#f2ece1",
      "stage_edge": "#d4dbdc"

    "typeface": "serif",
    "title_box": [

    "subtitle_box": [

    "photo_box": [
      171,

    ],

    "title_align": "center",
    "page_margin": 22,

  "pages": [
    {
      "image": "breakfast/v001.png",

```

示例须按真实照片和成图文字改写。`pages` 数组就是内容页顺序，支持 2–50 张；`cover` 是从 0 起算的封面照片位置。封面、序言、结语及封底由阅读器排成书页，所选封面照片仍保留自己的正文页。图片路径相对图册稿解析，也可用绝对路径。标题和 alt 必填。书名建议 16 个汉字以内，序言和结语各约 100 字以内，页脚约 40 字以内；过长文字会缩小，无法完整排下时明确报错，不截断。旧稿的 `scroll`、`pages` 可读入；缺少 `design` 时先依据该册照片和故事补齐，再按实体书方式装订。旧 HTML 不受影响。

`design.palette` 的七个颜色均为 `#RRGGBB`；封面文字与封面、正文文字与纸张须保持至少 4.5:1 对比。材质 `cloth`、`paper`、`smooth` 是可组合的渲染能力，字体 `serif`、`sans`、`handwritten` 使用当地可用字体，不是整套主题。封面 `title_box`、`subtitle_box`、`photo_box` 是 `[x, y, width, height]`，在 600×700 的设计区域内自由安排；`photo_box` 可为 null，表示文字封面。`title_size` 24–96，`title_align` 为 left/center；`page_margin` 0–60，`turn_ms` 500–2000，`hold_seconds` 2–8。`intro_title`、`ending_title` 可另外指定，缺省仅用“序言”“结语”。设计理由留在私密稿中，分享 HTML 只包含实际渲染参数。

```sh
"$PD_PYTHON" "$PD_SKILL/scripts/album.py" "$PD_WORK/album-v001.json" --output "$PD_WORK/album-v001.html"
```

导出器方向归一、转 sRGB、剥离元数据，将长边至多 2400 像素的 WebP 阅读副本内嵌到单文件 HTML。原文件保持不变；HTML 是阅读副本，不是无损原图存档。没有远程图片、字体或脚本依赖。单册超过 64 MiB、某张缺失或不能安全解码时整次导出失败。目标必须不存在，更新时另存新版本。

## 翻页与动画导出

阅读器从合上的封面开始，支持打开、左右翻页、合上封底、自动翻阅、键盘方向键和触摸滑动。下方“大图阅读”保留完整 Plog、目录和文字，支持窄屏细看、读屏与无脚本环境。系统要求减少动态效果时，手动翻页立即切换；用户主动导出动画时保留完整翻书动作。

页面中的“导出翻书动画”通过浏览器本地录制同一套书本画面：封面停留 → 开书 → 各跨页停留与翻页 → 合书与封底停留。只录书本画面，不录浏览器工具栏或其他屏幕，也不请求摄像头、麦克风或屏幕权限。可选横屏 1280×960、竖屏 1080×1440，默认使用本册设定的停留时间，并提供 2.5、4 或 6 秒选择。输出无声视频；格式选项只显示当前浏览器实际支持的 MP4/WebM，不能把 WebM 改后缀冒充 MP4。

录制按实际时长运行，请保持页面前台；切到后台或按取消会停止，不下载残缺视频。完成后自动下载，并保留“再次下载”入口。浏览器不支持录制时仍可读书，明确提示用支持该能力的 Chrome/Edge；不能把 HTML 成功误报成动画成功。动画最长随页数和停留设置增长，开始前让用户看到所选停留时间。

Agent 需要交付视频时，应在支持该能力的浏览器打开 HTML，实际完成导出并检查文件能解码、尺寸与页序正确、翻页连续、最后到达封底，再附上视频文件。用户要求的编码格式未被浏览器支持时，可以使用已可用的本地视频工具转换，保留原导出文件，并验证转换结果；不能只交一个按钮就宣称视频已生成。

## 检查、交付与修改

核对每页的图片、原文、顺序及故事衔接，完整保留 Plog 画内文字。检查桌面、手机的封面、跨页、翻动中间态及最后合书，测试反向翻页、快速连点、自动播放停止、动画下载和取消。程序检查不代替内容核验。

交付可打开的 HTML 及已实际导出的视频链接或会话附件；简述全书线索。页面“保存书本”保存包含全部 Plog 的 HTML，“打印书页”打印平面内容。生成文件不等于公开上线；托管仅在用户要求后执行。图册稿留在私密作品目录，供后续修改使用。

改书名、页脚、顺序或封面时更新选定图册稿并另存新 HTML；改画内文案或视觉时先修订该页 Plog，再重新装订。单张 Plog 的版本与全书版本分开保留。重新装订需要图册稿引用的图片可用；旧 HTML 仍能独立阅读，不把压缩阅读副本静默替代原图。
