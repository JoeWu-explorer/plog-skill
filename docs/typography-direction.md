# 文字表现力的设计方向

依据所有者此次明确选择，首次设计在场景允许时更主动地采用有视觉分量的文字，让文字与照片共同形成作品。重点是尺度、语义层级、强调色和图文位置共同作用，而不是把所有字统一放大或加粗。

运行规则见 [逐图艺术指导](../photo-dialogue/references/art-direction.md#文字参与构图)。大字不等于重滤镜；充分使用安全留白不等于贴近人物轮廓或挤满画面。具体字体、配色、位置依照片重新设计，保留安静、无字、长原话和限定修改的原有约束。

本次只根据已提供的对照图调整指导规则，未发送这两张私人图片到图像服务，未将图片或其中的文案放入仓库。新的疏朗/密集场景成图回归尚未执行；规则更新不能被报告为实际生成质量改善，也不改变既有验收失败统计。

本机已安装运行候选 `1dbab50`。38 项确定性测试、运行引用/资产检查和本地自检通过；这些结果只验证工程边界，不代表字号、构图或感染力已通过新一轮成图验收。
