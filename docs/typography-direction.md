# 文字与排版的设计方向

Plog 的文字参与构图。Agent 先根据照片找到值得被看见的语义落点，再决定字形、主次层级、断行和位置；文案、光色、氛围与排版由同一张照片的证据和用户偏好共同决定。

## 让表达更鲜明

需要展示图、封面或更有张力时，明确一个主视觉词组，用有理由的字号、字重、字面宽窄和位置差异安排阅读节奏。天空可以容纳舒展的笔势，窄墙可以形成纵向字阵，人物上方可以用小字铺垫、大字落句；这些是空间关系的例子，不是按照片类别强制套版。

字体也需要设计：笔画粗细、字腔、收笔和基线节奏应与照片呼应。不能只把两行普通字统一放大，也不能把“提示词里写了大字”当成实际效果通过。强表达请求在 390 CSS px 宽检查重点是否醒目、阅读是否清楚、字形是否仍有辨识度。

主体、人物动作与可见场景始终保留。提高文字表现力不自动增加滤镜强度；安静、无字、长原话或限定修改仍按用户要求处理。

## 图中文字不以句号收尾

创作配文默认不加句末「。」或「.」，包括旁白、标题与注记。问号、感叹号按实际语气保留，不机械替换句号。句中逗号、冒号、小数点、缩写与原照片招牌不受影响。

用户确认的原话保持原样，除非用户要求调整标点。只去句号时，其他文字、字体、位置、光色和摄影内容都属于需保持的决定；生成式编辑若带动这些内容，不能当成符合“只改标点”的成功版本。
