# 上手引导与文档整理

本次只调整使用入口、对话措辞和文档组织，保留全部生成、无字、画幅、修改、旧版恢复、导出、授权、失败保护和安装维护能力。生成服务、艺术指导、人物/文字核验门槛、文件与记录代码未变。

## 用户入口

首页按“发照片 → 说明想法 → 查看与修改”组织，给出可直接复制的首次请求。可选背景不变成必填表单，已有授权不重复询问。完整使用、排错和安装维护分别集中在 guide.md 与 install.md。

运行入口增加按状态组织的话术指引：说明当前发生的事、用户需要做的下一步，以及必要的限制。内部术语留在工具操作；既有成图的链接原样使用工具结果。生成失败、保存失败和入口展示失败分别处理，不用虚构状态或承诺引导用户。

## 仓库结构

README 面向首次使用者；docs/README.md 提供使用、版本证据和开发导航；CONTRIBUTING.md 说明目录职责、验证与打包入口。五份历史报告移至 docs/history/，同步修复相对链接。prototypes/README.md 标明原型只作历史研究。

归档保留完整报告与旧失败，未删除图片、代码或测试。已发布 alpha 的下载和视觉成绩与开发版本分开，原型不冒充正式产品展示。

## 验证范围

检查所有仓库 Markdown 本地文件链接、运行引用和资产清单；确定性测试验证现有文件/版本/安装功能仍可用。对话改动另以干净宿主检查首次上手、缺授权、拒绝外发和旧作品重显等不生成图片的场景。具体完成结果在本次 PR 中记录。

这不是新的完整视觉验收，不改变原生成质量限制，也不替换已发布 alpha 的附件。
