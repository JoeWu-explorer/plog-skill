# 使用指南

[返回首页](../README.md) · [安装指南](install.md)

## 第一次做 Plog

在已安装技能的 Agent 里发照片，说：

> 使用 plog，把这张照片做成 Plog，文字自然一点。

人物、山海、城市街景、食物、日常物件和宠物都可以。无人照片不需要补人物；人多也可以用一段旁白。可以一次提供一组照片，按指定顺序逐张创作，各自保留版本，不会自动拼成一个虚构场景。

首次使用外部读图或编辑服务前，会说明实际接收照片的服务与本次用途。已有同一范围同意时直接继续；新增服务或新照片要核对授权范围。照片已传到当前聊天，不等于授权转交另一家服务。没有外发同意时可先聊文案，完整成图需可用且获准的视觉／编辑能力。

不用先选字体或布局。AI 根据主体、光影、留白和想记录的瞬间决定文字与画面；生成前简短说明方向。

## 可以补充什么

- **经历**：“这是周末散步时拍的雨天路口。”
- **地点与日期**：“这是青岛，想写上城市名。”未提供时不会猜地点或编造旅行经历。
- **原话**：“右边的人说『今天慢一点』，原样保留。”
- **偏好**：“清透一点。”“别太煽情。”“做成竖版 3:4。”“不加文字。”
- **组图**：“三张按海边、街头、咖啡的顺序，统一成一个周末主题。”

默认简短旁白；有明确互动时可用对白，宠物或物件拟人化属于创作配文。创作文字不代表人物真实说过或想过。

## 修改与旧版

检查通过并保存后，交付 PNG 预览和同版文件。直接说“只改文字”“氛围淡一点”“把字移开海岸线”，或者“从第一版继续”。修改成功才新增版本，失败保留旧版。

新会话继续修改，请提供原图与作品目录（远程 Agent 需能实际访问这些文件），并说明使用哪一版。原图用于核对山形、街道、物体与人物等特征，旧版用于延续文案与设计。只查看旧图不需要原图，也不需要再次生成。

一组 Plog 每张独立保存，修改时指明第几张。某张失败会单独说明；不会把部分成功称为整组完成。

## 保存与交付

默认保存在 Agent 执行环境的 `~/Pictures/PhotoDialogue/`，也可指定私密持久目录。远程服务器或沙箱里的文件不自动出现在手机上：Agent 应通过当前对话的文件附件交付。原始文件和整个作品目录值得保留，方便恢复。

原图不覆盖；默认只保存成图 PNG 与最小版本记录。需要时可以导出纯文字或无障碍说明。未保留历史完整提示词时，重建内容会明确标注。

成图清理文件里的定位与设备元数据；画面中可见的地址、证件、学校信息需另行处理。图片上传后的服务保留政策以实际服务为准。

## 遇到问题

| 情况 | 下一步 |
| --- | --- |
| 没发现技能 | 检查该 Agent 的安装目录，并刷新或新开会话加载 `plog`。 |
| 能聊天但看不了图片 | 配置视觉模型／工具或兼容视觉 API。文字模型不能凭描述判定照片保真。 |
| 能读图但不会编辑图片 | 配置支持实际照片输入的图片编辑工具／API；纯文本生图不够。 |
| 动画、多页、RAW 或损坏图 | 提供支持格式的静态照片；不会静默取首帧。 |
| HEIC 读不了 | 配置可选 HEIF 依赖，或改用 JPEG、PNG、WebP。 |
| 关键主体无法核验 | 按具体提示补清楚原图或调整需求；不会编造五官、招牌或地形。 |
| 服务失败或超时 | 不自动重试；你可明确要求再试一次。超时请求可能已被服务处理。 |
| 错字、主体变样 | 候选不作为合格版本；可明确重试或改要求。 |
| 保存了但附件没显示 | 要求重发该版本，提供作品目录；无需重新生成。 |
| 想结束 | 说“停止”，后续不再处理；已提交服务请求不保证能撤销。 |

兼容性与视觉验收状态见 [Agent 适配](agent-compatibility.md)。
