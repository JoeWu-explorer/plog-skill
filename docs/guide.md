# 使用指南

[返回首页](../README.md) · [安装指南](install.md)

## 第一次做图

在 Codex 对话中发一张照片，并说“把这张照片做成中文叙事图”。也可以写 `$photo-dialogue` 明确调用。

第一次处理这张照片、还没有明确同意时，会简短确认：

> 我会把这张照片交给 Codex 图像服务，配上中文并做成图片。这次同意仅限这张照片的生成和后续修改，成图会保存到你的电脑。可以开始吗？

回复“可以”“好”或“ok”就会继续，不需要照着固定句式授权。已经明确同意、同一范围内继续修改时不再重复确认。暂时不想处理照片，也可以先聊聊配什么文字。这里说明的是操作同意范围，不是图像服务的数据保留政策。

不用先选字体、色调或布局。可见动作足够时，仅照片也能开始；如果某个人说了哪句话不清楚，才会问必要的问题。生成前会用一句话说明本次方向，例如“我会围绕一起包饺子的动作配一句短旁白，文字避开人物和手部”。

## 哪些信息值得补充

- **场景**：“周末，夫妻俩一起包饺子。”姓名、关系和背景以你提供的信息为准。
- **原话**：“左边的人说『你拌餡，我來包。』，请原样保留。”原话及繁简用字会按要求核对。
- **偏好**：“自然一点，别太煽情。”“用冷一点的色调。”“不加文字。”
- **画幅**：“做成竖版 3:4。”不指定时保留原方向；如果调整会影响人物或文字，会说明冲突。

没有提供原话时，生成的对白或内心文字属于创作，会明确说明，不代表照片人物真的说过。

## 查看、修改和返回旧版

检查通过并保存后，回复会包含成图预览和同一版本的 PNG 下载入口。每次通常交付一个方案。

直接说“只改文字”“氛围淡一点”或“把文字往上移”，也可以一起说明多项修改。修改成功后新增版本，旧版保留；失败不会替换已有作品。只想查看旧版时，说“展示第一版”，不需要重新生成。

新开对话后继续修改，请提供**作品目录和原图**：

> 使用 $photo-dialogue，从这个作品的第一版继续，把字移到上方。作品目录：〈目录〉；原图：〈路径〉。这次允许把所选版本交给 Codex 内置图像服务修改。

选择旧版时会沿用那一版的文案和设计。原图用于核对人物，记录用于找回版本；原图缺失或变更时，需要你指明正确文件。仅查看已有作品不需要原图，也不需要图像服务授权。

## 保存、导出和隐私

作品默认在 `~/Pictures/PhotoDialogue/` 的独立目录中；你可以指定其他位置。保留整个作品目录和原图，便于以后继续修改。

默认交付 PNG，另存最小修改记录。需要时可以说“导出这一版的纯文字”“给我无障碍说明”或“给我生成提示词”。历史提示词没有保留时会明确说明；根据记录重建的内容会标为重建，不冒充原始调用。

原图不覆盖，成图会清理源定位和设备元数据。但照片**画面里可见**的地址、学校或证件文字不等于文件元数据；有这类信息时请说明希望如何处理，必要时会先确认。

## 遇到问题怎么办

| 情况 | 下一步 |
| --- | --- |
| 找不到技能 | 确认已安装，新开 Codex 对话后输入 `$photo-dialogue`；仍不出现时按安装指南检查。 |
| HEIC/HEIF 无法读取 | 提供 JPEG、PNG 或 WebP，或按安装指南配置可选 HEIF 依赖。 |
| 照片过暗、损坏、人物无法辨认 | 根据提示提供可读取、人物更清楚的照片；技能不会猜测人物细节。 |
| 超过六名参与者，或动画、多页、RAW | 换一张支持范围内的静态照片；不会静默裁人或取其中一帧。 |
| 图像服务不可用或这次生成失败 | 若想对当前请求再尝试一次，明确说“再试一次”；不会自动重试。服务恢复和再次成功均不保证。 |
| 字太小、错字或人物变化，检查未通过 | 这张不会保存为合格版本。可以明确要求重试，或修改需求；已有作品保留。 |
| 图片已保存，但预览或链接没显示 | 说“重新展示这个作品的这一版”，并提供作品目录；无需重新生成。 |
| 没找到原图或指定版本 | 提供正确原图或版本信息；不会擅自改用另一张照片或最新版。 |
| 想结束 | 说“停止”。保留已经保存的版本，不再发起后续处理；已经提交的服务请求未必能撤销。 |

目前是试用版，尚未达到完整发布验收要求。支持的照片类型不等于每张都能成功；实际结果与限制见 [版本与验收](README.md#版本与验收)。
