# 发布文案草稿（未批准发布）

照片有话说，是一个在 Codex 里使用的中文照片创作 Skill。发一张人物照片，可补一句场景，它会根据这张照片决定对白或旁白、光色、字体和构图。之后可以直接说“这句话换自然一点”“氛围轻一点”或“从第一版继续，把字移开手部”。

人物和文字需要逐图核验；生成式处理仍可能失败。失败会明确说明，保留已有作品，不自动重试或换成简单贴字。作品和最小修改记录在本地保存，图像生成需要当次知情授权并使用 Codex 图像服务。

当前仍为开发候选。正式发布时补入经验证的固定版本安装入口、三场景真人审阅示例以及如实的环境/样本统计；这些尚未获得证据，因此此文案不可直接当作已发布公告。
