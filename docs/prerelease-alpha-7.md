# v0.1.0-alpha.7 · Plog 故事书

把多张照片串成一本可以打开、翻阅和导出动画的 Plog 故事书。先根据照片与故事编排全书，逐页创作或复用已完成的 Plog，再装订成可离线打开的 HTML。

## 本版更新

- 封面、序言、左右书页、结语与封底；支持正反翻页、自动翻阅、键盘和触摸操作，以及大图阅读与打印。
- 根据每册的照片、故事与用户偏好决定材质、配色、字体、封面构图和阅读节奏。设计依据保存在本地图册稿中，样册风格不会作为通用默认。
- 在浏览器本地导出从开书到合书的无声视频，可选横屏、竖屏与停留时间；MP4/WebM 由浏览器实际支持决定。阅读和视频使用同一套画面。
- HTML 内嵌全部图片，可离线保存和分享；原图、单张 Plog 版本和既有图册不会被覆盖。支持从 alpha.6 固定发布包升级。

## 安装与使用

```sh
npx skills add https://github.com/JoeWu-explorer/plog-skill --skill plog
```

发照片后说：「把这些照片串成一本可以打开和翻页的书，每一页都做成 Plog，故事接起来，再导出翻书动画。」

固定版本使用本页 `plog-v0.1.0-alpha.7.zip` 与 `SHA256SUMS`。已有图册稿若缺少 `design`，需要先根据该册照片和故事补齐装帧记录，再重新导出；旧 HTML 仍可独立阅读。

## 验证与当前边界

本版在最新 main 上集成：69 项确定性测试、类型检查和仓库公开许可检查通过，另验证固定包可复现构建、全新安装、自检、真实 alpha.6 包升级、独立成册及卸载。浏览器实测覆盖翻页、自动翻阅、视频下载与取消、保存后重开、打印、手机、减少动态效果和无脚本阅读。

书本目前使用 Canvas 模拟立体翻页，尚未实现真正的 3D 模型。样册复用既有 Plog 成图，尚未完成新用户照片从逐张生成到成册、动画的完整端到端验收；完整 Agent／图像服务和人工视觉矩阵仍待执行。动态设计有明确的渲染参数范围，不宣称支持任意材质或任意书型。

实际固定提交、包校验值及托管 CI 结果见 [版本清单](https://github.com/JoeWu-explorer/plog-skill/blob/v0.1.0-alpha.7/docs/release.json)。本次发布为预发布版。
