# Strong Look exploratory outputs

These are unaccepted visual prototypes, not production fixtures or proof of identity fidelity.

- Source: repository fixture `02-spouses-cooking.png`, an original CC0 image of fictional people. No private real-person photo was submitted.
- Tool: built-in OpenAI imagegen, 2026-09-05.
- User authorized an experiment with overall stylization while preserving identity, expression and action, then explicitly requested filters and atmosphere.
- `strong-warm-editorial-v1.png`: edited from the source; exact prompt in `../strong-look-prompt.txt`.
- `strong-warm-film-v2.png`: edited from v1 with the original source also supplied for identity; exact prompt in `../warm-film-prompt.txt`.
- The reference project's public art direction and sample wall informed high-level analysis only. No third-party artwork, source code, token file or reference plate was submitted to the generator or copied here.

## Readback

Both outputs visibly contain the intended Chinese text, exactly two adults, the shared mixing bowl, dumplings and the core stirring interaction. No obvious additional person or limb was observed. The broad identities and smiles are recognizable, but faces, hands, bowl details, proportions within the frame and colors have been re-rendered; identity fidelity is not certified by this inspection.

The film edit deepens shadows and changes texture. It remains quite warm/orange and did not fully deliver the requested cool-shadow separation or reduced yellow wash. It must be shown as an experiment awaiting feedback, not a passed atmosphere standard.

This prototype deliberately tests model-integrated Chinese lettering and a narrative poster composition. It is not the previously specified text-free generated base followed by local text rendering, nor a verified implementation of the three deterministic Recipes. No production contract is silently replaced: typography pipeline, default Look scope and layout decisions must be reconciled if the user endorses this direction.
