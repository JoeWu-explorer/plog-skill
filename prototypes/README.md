# 历史设计原型

这里保存设计决策和试验，不是正式产品入口，也不能当作已通过验收的效果展示。

| 目录 | 内容 |
| --- | --- |
| `layout-recipes/` | 版式与多人互动的早期研究 |
| `look-system/` | 光色、字体和视觉方向试验，含未清许可的历史图 |
| `first-run/` | 首次生成、修改和失败体验的交互原型 |
| `acceptance/` | 验收与安装包合同提案 |

使用产品请看 [首页](../README.md)，正式行为由 [运行技能](../photo-dialogue/SKILL.md) 定义。资产许可见 [清单](../docs/assets.json)。
