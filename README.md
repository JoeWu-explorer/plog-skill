# 照片有话说

发一张人物照片，让画面里的时刻有一句合适的话。光色、字体和文字位置按照片设计，之后可以直接用自然语言修改。

这是在 **Codex 对话里使用的 Skill**。目前为 alpha 试用版；低照、人物密集或文字较长时仍可能失败。[查看版本与已知限制](docs/README.md#版本与验收)

## 开始使用

已安装的用户，在 Codex 对话中上传一张照片，然后说：

> 使用 $photo-dialogue，把这张照片做成中文叙事图。这次允许使用 Codex 内置图像服务处理这张照片。

还没安装？先看 [安装指南](docs/install.md)。技能首次没有出现时，新开一个 Codex 对话再试。

1. **发照片**：支持一张含 1–6 人的静态照片。可以补一句背景，比如“夫妻一起包饺子”。
2. **说明想法**：没有特别要求就交给技能设计；有原话、指定人物或喜欢的氛围，也可以直接说。
3. **查看作品**：检查通过并保存后，会给你预览和 PNG 下载链接。想调整，继续在同一对话里说就行。

没有提前说明外发授权时，会先告诉你使用哪张照片、交给什么服务、做什么，再询问本次是否允许。已明确授权的同一次处理不会重复确认。

## 想改哪里，直接说

| 你想做什么 | 可以这样说 |
| --- | --- |
| 换一句话 | “只把文字改成『今天慢一点』，其他尽量保持。” |
| 减轻滤镜 | “别这么黄，文字和位置保持。” |
| 移动文字 | “把字移到上方，避开手。” |
| 返回旧版 | “从第一版继续，保留原句，只把字往上移。” |
| 不加文字 | “这张不加字，只调整氛围。” |
| 查看旧作品 | “重新展示这个作品的第一版：〈作品目录〉。” |

每次修改会保留旧版本。生成式编辑无法保证其余像素完全不变；人物或文字不合格时会说明原因，不把失败图当成成品。

## 照片和作品放在哪里

照片会在获得本次授权后发送到 **Codex 内置图像服务**，不是完全离线处理。原图不会被覆盖，作品默认保存在 `~/Pictures/PhotoDialogue/`，也可指定位置。作品目录保留 PNG 和继续修改所需的最小记录。
