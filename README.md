# 照片有话说

在 Codex 中发一张人物照片，生成带中文对白或旁白的图片，再用自然语言修改。字体、字号、光色和位置按照片与内容决定，也支持不加文字。

**当前版本：[v0.1.0-alpha.2](https://github.com/JoeWu-explorer/photo-dialogue/releases/tag/v0.1.0-alpha.2)** · [安装](docs/install.md) · [使用指南](docs/guide.md) · [更新记录](CHANGELOG.md)

## 怎么用

安装后，在 Codex 对话中上传照片并发送：

> 使用 $photo-dialogue，把这张照片做成中文叙事图。

首次需要确认时，会说明照片交给 Codex 图像服务处理、用途和同意范围。回复“可以”“好”或“ok”即可继续；已有明确同意、同一范围内继续修改时不重复确认。

1. **发照片**：一张含 1–6 人的静态照片，可补充背景或指定原话。
2. **生成作品**：技能决定文字与设计，检查通过并保存后给出预览和 PNG 下载链接。
3. **继续修改**：直接说想改什么，旧版本保留。

| 想做什么 | 直接说 |
| --- | --- |
| 改文字 | “只把文字换成『今天慢一点』。” |
| 调氛围 | “别这么黄，文字和位置保持。” |
| 移文字 | “把字移到上方，避开手。” |
| 用旧版 | “从第一版继续，只改文字。” |
| 不加字 | “只调整氛围，不加文字。” |
| 看旧作品 | “展示这个作品的第一版：〈作品目录〉。” |

## 支持与限制

- 静态 JPEG、PNG、WebP；HEIC/HEIF 需可选依赖。运行环境为 macOS/Linux、CPython 3.11–3.13，以及具备图像能力的 Codex。
- 图片经本次授权后发送到 Codex 内置图像服务。作品默认保存在 `~/Pictures/PhotoDialogue/`，原图不覆盖。
- 支持指定旧版继续修改、纯文字等按需导出、明确重试、停止、更新和卸载。详见 [使用指南](docs/guide.md)。
- **这是试用版，尚未通过完整视觉验收。** 低照、密集人物、长文字仍可能失败；不保证人物细节或非修改区域的像素完全不变。检查失败时会说明原因，不自动重试。
